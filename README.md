# 📊 Sistema de Relatórios com Filtros Dinâmicos

Este projeto é uma aplicação web desenvolvida com **Next.js 13+ (React 19)** que permite aos usuários gerar relatórios dinâmicos com base em filtros de seleção de tabelas e colunas de um banco de dados. A interface foi construída utilizando a biblioteca de componentes **Shadcn/UI**, proporcionando uma experiência moderna, acessível e responsiva.

## ✨ Funcionalidades

- 🔍 **Seleção dinâmica de tabelas** do banco de dados.
- 📑 Escolha das **colunas desejadas** para exibição.
- 📊 Geração de **relatórios personalizados** com base nas relações e filtros aplicados.
- ⚡ Interface limpa, moderna e responsiva com componentes do Shadcn.
- 💾 Integração backend para busca de metadados e dados reais.

---

## 🧪 Tecnologias Utilizadas

- [Next.js 13+](https://nextjs.org/) com App Router
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Shadcn/UI](https://ui.shadcn.com/)
